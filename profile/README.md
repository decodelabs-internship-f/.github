# Decodelabs Internship Projects

A collection of projects completed during my internship at **Decodelab**, covering robotics, automation, and industrial vision systems.

## Projects

### 🦾 [ROS Robotic Arm](https://github.com/decodelab-internship/ros_robotic_arm)
6-DOF robotic arm inverse-kinematics solver and trajectory planner built for ROS2.

### 🤖 [AMR Simulator](https://github.com/decodelab-internship/amr_simulator)
Autonomous Mobile Robot (AMR) simulator and demo written in Python, used to test navigation and motion logic.

### ⚙️ [PLC Conveyor Sorting](https://github.com/decodelab-internship/plc-conveyor-sorting)
Industrial PLC-based conveyor sorting system (IEC 61131-3 Structured Text + ladder logic), with a Python simulator, safety interlocks, and unit tests.

### 🔍 [Automated Optical Inspection](https://github.com/decodelab-internship/Automated-Optical-Inspection)
OpenCV-based defect detection system that flags missing components or cracks on a conveyor belt using golden-template comparison and contour detection.
